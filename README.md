# 📝 Character and Word Counter

A simple and responsive web application that counts **characters, words, and sentences in real time** as the user types.

## 🚀 Features

- 🔤 Live character count
- 📝 Live word count
- 📖 Live sentence count
- 🔢 5,000 character limit
- ⏳ Remaining character count
- 🧹 Clear button
- 📱 Responsive design
- ⚡ Real-time DOM updates
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
